## PowerShell Guide
This repository now includes a comprehensive PowerShell (pwsh) guide:
- `PowerShell-Guide.md` - Complete guide on how to use PowerShell commands
- `example-script.ps1` - Sample PowerShell script demonstrating academic use cases

### How to run PowerShell commands:
```bash
# Open PowerShell interactive shell
pwsh

# Run a single command
pwsh -Command "Get-Date"

# Execute the example script
pwsh -File example-script.ps1
```
